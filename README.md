# Infograph

Structure information, experiences and their relationships in a factual, human-writable, language-agnostic graph: the infograph.

Query the infograph with restrictions to produce simplified representations, which can be used to make

- reports
- writeups
- presentations

Think of it like a Venn diagram. The set of graph elements yielded by the query represents the active presentation surface. It is a subset of all graph elements.

Edges that cross the boundary between active and inactive nodes is become "handles" for Q/A, feedback or discussions, and can be represented as such in artifacts. The speaker knows inactive content, and can dive into it on demand.

## instructions

- keep prose factual
- avoid excess or filler words
- technical words and jargon used in source material allowed. Do not artificially simplify language.
- present tense should suffice outside of special cases : avoid summaries and past tenses merely because the node is not currently active.
- present tense statements need not be true right now. Consider application in date or date range period of the current node. For edges, consider the present is the interesection of the date ranges of both nodes.
- Use past and future tenses when you find yourself needing to refer to something outside the node or edge's active time period.
